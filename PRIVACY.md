# Privacy in Qlicker

Start with [Your data in Qlicker](docs/privacy/notice-template.md): a short page explaining what is saved, what instructors and administrators can see, and what anonymous activities mean. Each institution fills in its contact details, retention periods, and any external services it uses before publishing it.

## For administrators and developers

- [Proposed app changes](docs/privacy/app-proposal.md): a public Privacy page, simple admin settings, retention controls, and per-course permission to view response IP addresses.
- [Data-handling reference](docs/privacy/data-handling.md): the current software behavior and supporting code references.
- [Ontario deployment guidance](docs/privacy/ontario-deployment.md): background for the institution's privacy office.

The public page should be easy to reach from sign-in, account creation, and inside the app. The proposed page and controls are not implemented yet; institutions can publish the completed notice on their own website in the meantime. These documents do not change application behavior.
